CONNECTION & PRIVACY

From meter to live dashboard.

The collector reads raw meter telegrams on the home network and uploads readings over HTTPS. If a request fails, readings remain in a local queue until the server acknowledges them.

The dashboard checks for updates automatically every 15 seconds. Summaries are prepared once per minute, so viewing the dashboard does not repeatedly scan the full measurement history. The collector needs to stay on; the device displaying this dashboard does not.

Anyone with the dashboard URL can view the readings. Uploads from the collector require a secret key. The timestamp of the latest water-meter measurement is shown because water values update at the meter’s own pace.

Usage and cost are calculated from cumulative meter readings. Allocations across gaps are marked as estimates. The unverified Wh value is excluded from cost calculations. During an outage, the dashboard may show clearly labelled last-known data.
